## 🤝 ร่วมงานกันได้แบบไหน / How we can work together

- **มีโจทย์ธุรกิจ อยากได้ระบบ** — คุยกันได้ตั้งแต่ยังไม่มีสเปก ผมช่วยตีโจทย์ ประเมินขอบเขตและงบให้เห็นภาพก่อนเริ่ม
- **มีระบบเดิมอยู่แล้ว แต่ไปต่อไม่ไหว** — รับตรวจสุขภาพระบบ วางแผนปรับปรุงหรือย้ายแพลตฟอร์ม
- **กำลังหา CTO / Tech Advisor** — รับทั้งแบบเต็มเวลาและแบบ fractional/ที่ปรึกษา
- **เป็น developer และอยากร่วมทีม** — ทีมเปิดรับคนที่อยากทำระบบจริงที่มีคนใช้งาน ทักมาคุยได้เลย
